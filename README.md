# Java Support Library

General-purpose Java support code, useable in most Java projects.

The intention is for this library to have as few third-party dependencies as possible, in order to not burden down-stream users with these same dependencies.

Published as a Maven package on [GitHub Packages](https://github.com/gpellicciotta/support.java/packages/), licensed under the [MIT License](LICENSE.md).
